# Smart_car_using_flask-facedetection
This paper involves the design and
development of an intelligent, web-controlled vehicle
integrated with advanced safety and security features. By
utilizing smart automotive technology, the system
enhances accessibility and convenience by allowing using
users to remotely manage the vehicle’s movements via a
web interface that can be accessed from any internet
enabled device. Robust safety features such as collision
detection and drowsiness monitoring are incorporated in
the car to prevent accidents and ensure driver alertness.
A panic button is also incorporated to alert emergency
contacts with the car’s present location during critical
situations. For improved monitoring and convenience of
the users the system also offers real time vehicle tracking.
Security is further with integration of an intruder alert
system that takes picture of any unauthorized person
trying to access the car. This is an all-inclusive solution
that combines security, safety and control into a single
intelligent platform.

Keywords—ESP8266, WebSocket Server, Smart Car,
Location Tracking, MPU6050, Drowsiness Detection
